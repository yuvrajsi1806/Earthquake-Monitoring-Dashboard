# Earthquake Monitoring Dashboard

## Project Overview

The Earthquake Monitoring Dashboard is an interactive data visualization project designed to monitor and analyze earthquake activities using publicly available seismic data.

The project processes earthquake information and presents meaningful insights through interactive dashboards, maps, charts, and key performance indicators (KPIs).

It aims to make earthquake data easier to understand by providing information about earthquake magnitude, geographical distribution, frequency, and trends.

## Key Features

- **Earthquake Data Monitoring:** Collects earthquake information from publicly available seismic data sources.
- **Automated Data Fetching:** Integrates seismic APIs to retrieve updated earthquake information.
- **Interactive Dashboard:** Displays earthquake information through dynamic visualizations.
- **Geographical Visualization:** Uses maps to represent earthquake locations.
- **KPI Monitoring:** Presents important earthquake statistics and metrics.
- **Trend Analysis:** Helps identify earthquake patterns based on historical and recent data.
- **Data Processing:** Cleans and organizes raw earthquake datasets for analysis.

## Project Modules

### 1. Data Collection
Retrieves earthquake information from publicly available seismic data APIs.

### 2. Data Cleaning and Processing
Processes raw earthquake datasets and prepares them for analysis.

### 3. Database Management
Uses SQL for storing, querying, and managing earthquake information, where applicable.

### 4. Data Visualization
Creates interactive charts, maps, and reports using Power BI.

### 5. Dashboard and KPI Analysis
Displays earthquake statistics, magnitude distribution, geographical patterns, and activity trends.

## Dashboard Insights

The dashboard can present metrics such as:

- Total recorded earthquakes
- Earthquake magnitude distribution
- Geographical distribution of earthquakes
- Earthquake activity over time
- Highest recorded earthquake magnitude
- Recent earthquake activity
